## Only the tools a turn needs (PRO-392, D-168)

**Not in use since PRO-1291:** `chat()` sends every tool and the whole prompt again, because a set that changed from turn to turn broke the prompt cache (see «Model and loop → Every tool and every rule on every turn»). `selectToolGroups`, the groups and `more_tools` stay in the code (and in `runToolLoop`, for `scripts/evalHealthAnswers.ts --por-turno`). What follows is how it worked from 2026-11-11.

Until 2026-11-11 every request of Mimo carried all its tools (~90; ≈74 KB of names, descriptions and schemas, more than the rest of the prompt) and the whole «Sobre Mimoia» block (≈24 KB), on every round. Many tools at once also made the choice harder (Miguel, D-168). Now, per turn and without AI (`selectToolGroups`, `services/assistant/toolGroups.ts`):

- **A small core always goes:** `get_todays_menu`, `get_weekly_menu`, `get_recipe_details`, `search_recipes`, `swap_meal`, `get_shopping_list`, `add_shopping_items` and `more_tools`.
- **Groups:** `menu` (generate the week, add / remove / move / clear / lock meals, diners, notes, vetoes, eaten or cooked, who cooks, history, template), `sobras` (dish already made, leftovers, táper, freezer), `fijas` (fixed meals, school menu), `compra` (the list: remove, amounts, units, habituals, staples, bought), `tiendas` (shop orders), `despensa` (pantry, what to cook with what there is), `recetas` (create, edit, import, own recipes, cookbooks, favourites, notes and ratings, scale, substitutions, recipe of the day, cooking mode), `cocina` (cooking mode controls), `salud` (nutrition and balance), `hogar` (household, profile, memory, invitations, alerts, cooking style, feedback), `ficha` (the ficha and «Afina tu menú» ratings). Every tool is in the core or in a group (test).
- **Which groups:** those whose words appear in the user's message or in Mimo's previous reply (so «Sí, mételo» after the freezer review gets `plan_freezer_items`), the groups of the tools Mimo used in the last two turns (the ⟦hecho: …⟧ marks), and the page the web companion writes from (`/menu` → menu; `/shopping` → compra and tiendas; a recipe or the catalogue → recetas; cooking → cocina and recetas; `/profile` → hogar and ficha). Nothing matched → `menu`. The voice onboarding gets only `update_memory` (its prompt allows nothing else); the WhatsApp sign-up adds `complete_onboarding`.
- **`more_tools`:** if the model still lacks a tool it asks for its group (`groups: [...]`); the engine adds those tools to the next round of the same turn and answers «Ya tienes las herramientas de …». An unknown group is an error with the list. It only reads (`READ_ONLY_TOOLS`). A tool outside the set that the model calls anyway still runs (the engine looks it up in the whole registry).
- **The prompt follows:** the lines of «Instrucciones de herramientas» go only with their tools (`TOOL_INSTRUCTIONS`, `systemPrompt.ts`), and the lines that only repeated a tool's description (use `get_shopping_list` for the list, `toggle_favorite` for a favourite, `get_pantry_stock`, `scale_recipe`, the cooking-mode tools…) are gone; «nunca margarina, aceites refinados ni edulcorantes» stays always. The «Sobre Mimoia» block (facts, plans and prices) goes in only when the user's message asks about the app (Mimoia, precio, plan, pagar, suscripción, privacidad, mis datos, contacto, qué puedes hacer, cómo funciona…) and during the WhatsApp sign-up; without it, one line says not to make anything up and to look at mimoia.com, and the contact (email, phone) is always there.
- **Measured:** over the battery's cases, tools + instructions are ≈44 % smaller (test: under 70 % of before). `scripts/mimoInputTokens.ts [--desde] [--hasta]` gives the mean input tokens per turn from `cost_events` (production) and, in staging with «Mimo remoto», the mean size of each round's tools, system and messages from `mimo_turnos_remotos`.
- **The battery, before and after, by the subscription:** `scripts/evalHealthAnswers.ts` gives each case the fixed block the engine sends (`buildFixedBlock`, every tool since PRO-1291); `--por-turno` gives it only the tools of its turn (PRO-392), to compare; `--remoto` sends each round to «Mimo remoto» (needs the `DATABASE_URL` of the database the office answers, no API key); it ends with `pass^N: X/Y casos`.
- Tests: `mimoToolGroups.test.ts` (every tool grouped; every case of the battery, WhatsApp and web, gets the tools it simulates or must call; words, last question, past tools, pages, onboarding; «Sobre Mimoia» only when asked; the prompt's tool lines; `more_tools` in the engine).
